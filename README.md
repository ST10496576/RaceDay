# RaceDay
Programming a race day full stack system
System Description
RaceDay is a web-based event management system designed for the South African road running, walking, and cycling community. The system will allow organisers to create and manage events, categories, routes, and participant results. Participants will be able to register, manage their profiles, enrol in available event categories, and view their results.
Part 1 focuses on the planning and database foundation of the system, including the Entity Relationship Diagram (ERD), API endpoint plan, and SQL Server database script.
User Roles
Organiser
The Organiser is responsible for managing events on the RaceDay system. Organisers can create, update, and delete events and their categories, manage event enrolments, and add or manage participant results.
Participant
The Participant can register and manage their profile, view available events and categories, enrol in events, and view their own enrolments and results.
Part 1 Documentation
The docs folder contains:
•	ERD – Entity Relationship Diagram showing the structure and relationships of the RaceDay database.
•	API Endpoint Plan – Planned API endpoints, HTTP methods, roles, request bodies, and expected responses.
•	SQL Database Script – SQL Server script used to create the RaceDay database, tables, constraints, relationships, and sample data.
